# wbmm_core 质量声明

## 当前状态

- 版本：`0.1.0`；
- 成熟度：实验性核心合同；
- ROS 质量等级：暂不声明；
- 证据等级：目标为 L1（纯 C++ 单元测试），尚未代表 L2 规划、L3/L4 仿真或 L5/L6 实机验证。

## 公共 API

安装目录 `include/wbmm_core/` 下的头文件构成公共 API：

- `status.hpp`：错误码、`Status` 和 `Result<T>`；
- `types.hpp`：领域数据合同；
- `validation.hpp`：边界校验与差速底盘维度合同；
- `ports.hpp`：能力接口；
- `wbmm_core.hpp`：聚合头文件。

## 兼容性规则

- 遵循语义化版本；
- 增加可选字段或新错误码可进入次版本；
- 删除/重命名字段、改变单位/frame/时间/顺序语义必须进入主版本，并记录 ADR；
- 具体机器人、供应商或设备名称不得进入公共包名、目录名和核心类型；
- adapter 必须显式完成 ROS `xyzw` 与核心 `wxyz`、具名关节顺序及后端定长向量之间的转换。

## 变更门禁

每次核心合同变更至少需要：

1. 更新对应设计文档与字段映射；
2. 覆盖成功路径和错误路径的纯 C++ 测试；
3. 独立构建 `wbmm_core`；
4. 证明空 frame、NaN/Inf、错误维度、重复/错序关节和不一致 revision 会 fail closed；
5. 若影响 adapter，再由 adapter 包补充转换、集成与回归测试。

## 未覆盖范围

本包不声明求解器正确性、碰撞安全、实时性、ROS 通信、仿真一致性或实机安全。相关结论必须由上层 package 的独立证据给出。
